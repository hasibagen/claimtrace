**研究目的**（1-3 句:构建什么样的脑模型,用来回答什么"真脑上做不到"的问题）

**一、建模范式定位**

- **模型家族**: （从下方词表选或照抄原文;如 代理脑 ANN / TVB-Epileptor 神经质量 / 平均场 / 超网络 hypernetwork / DCM 状态空间 / VAR / 机理-数据混合灰盒）
- **学习范式**: 数据驱动(从信号学动力学) / 机理驱动(方程+拟合参数) / 灰盒(机理骨架+数据修正)
- **个性化机制**: 逐被试独立拟合 / 群体模板+个体参数修正 / 群体平均模型（**必写清,这是孪生脑"个体化"叙事的关键区分**）
- **模型在管线中的角色**: 一次性工具(推断完即弃) / 持续孪生(随新数据更新) / 干预模拟器

**二、模型规格**

- **输入**: 什么信号、多少节点/脑区、时间步长（如 360 区 BOLD, TR=0.72s, 前三步）
- **输出**: 下一时刻状态 / 下一时刻状态+未来轨迹 / 参数后验 / 连接矩阵
- **架构**: 层数-宽度-激活（或方程形式与状态变量）;自由参数量级
- **推理形式**: 模型怎么"回答问题"——直接读权重 / 虚拟扰动比差异(≈雅可比) / 反演后验 / 前向模拟对比
- **架构选择依据**: 网格搜索/文献沿用/拍脑袋（**拍脑袋要记入红旗**）

**三、训练协议 ★**

- **训练数据窗口**: 谁的、哪段时间（如 每被试 4 段×15 分钟静息态;或 前半段任务态）
- **学习任务**: 下一步预测 / 多步预测 / 重构 / 分类辅助 / 参数拟合
- **损失函数**: （MSE / 负对数似然 / 方程残差,照抄原文公式语义）
- **训练单位**: **逐被试 / 群体 / 群体预训练+个体微调**（与"个性化机制"呼应）
- **优化配置**: 优化器 / epochs / batch / 学习率 / 早停;算力与耗时（如 Adam, 60 epochs, batch 100, RTX 4080）
- **切分方式**: 训练/验证/测试怎么分——**按时间 / 按被试 / 随机洗牌 / 未声明**（随机洗牌+时序=红旗;未声明也要记红旗）

**四、保真度验证协议 ★**（回答"凭什么说它是合格的脑替身"）

- **验证统计量**: 拿模型的什么和真实的什么比（如 模型生成信号的 FC vs 经验 FC;功率谱;激发-抑制平衡;发作起始区）
- **在谁的数据上算**: **训练所用同一批被试（=拟合优度,不是泛化）/ held-out 被试 / 外部数据集**（必写清,混淆两者是常见弱点）
- **验证方式**: 自由生成（递归喂预测,看长程统计不发散） / 单步/多步预测精度（R² 等） / 参数恢复
- **指标与数值**: （r=…, R²=…, 照抄原文并注 §/Fig）

**五、外推测试协议 ★**（回答"超出训练情境还成立吗"——对齐 syntheses/孪生脑多维框架.md 维度十三）

- **外推方向**: 时间前推 / 状态外推（静息→任务,清醒→麻醉）/ 干预前后（基线→治疗结局）/ 群体间（健康→疾病,跨数据集,跨个体）/ 仿真到真实 / 重测稳定性（可多选,逐一列）
- **ground truth 类型**: 已知参数的仿真 / 独立外部测量（CCEP、随访结局、疗效）/ 无外部真值（只做内部一致性,要降级表述）
- **指标与数值**: （照抄原文并注 §/Fig）

**六、稳健性与泛化**

- **跨随机初始化 / 跨会话 / 跨数据集 / 跨架构**： 各自做了没有,数值多少
- **失败案例**: 模型在哪个脑区/哪类被试/哪个指标上不可靠（如边缘系统信噪比低）

**七、计算与复现**

- 代码/数据开源地址;训练一个模型的算力与墙钟时间;**个体化成本**（临床落地叙事的关键数字:单被试训练几分钟还是几天）

**八、深入浅出讲解 ★**（写给完全没读过原文的人;三层递进,每层独立成段）

- **比喻层**: 用一个生活比喻讲清"这模型在干什么、训练在学什么、验证在验什么"（一两句,后续 PPT 可直接用）
- **机制层**: 白话+少量术语,按"喂什么→学什么→怎么确认学像了→怎么用它做真脑做不了的实验"四问成段
- **协议层**: 精确到参数的训练-验证-测试一句话协议（如"逐被试用四段静息态,前三步预测下一步,MSE 损失;递归生成信号的 FC 对经验 FC 相关 0.97;跨数据集 HCP→ABCD 0.87、对 CCEP 0.33"）

**十、建模红旗清单**（逐项核对;命中即写入本节并考虑升为方法学 claim）

1. **时序随机洗牌切分**: 训练/测试按时间点随机洗牌而非按时间或被试切分 → 信息泄漏,预测指标虚高
2. **保真度冒充泛化**: 只报"训练同一批数据上的模型-真实匹配",无任何 held-out/外部数据,却声称模型可外推
3. **切分方式未声明**: 论文没写清 train/test 怎么分 → 预测指标存疑(维度十三方法学观察)
4. **无外部真值**: 结论只靠跨 seed/跨会话内部一致性支撑,无独立 ground truth,却用了因果/预测类强表述
5. **个性化与群体混用**: 逐被试训练与群体平均在文中交替使用而不声明,个体化结论不可靠
6. **测试集上调参**: 架构/超参按最终测试指标选取,无独立验证集
7. **虚拟干预参数缺失**: 扰动强度/刺激波形/假设参数未报告,虚拟实验不可复现
8. **架构无依据**: 模型结构选择无消融或搜索依据,且结论依赖该结构

> 记录格式示例:`建模红旗 #2:模型 FC vs 经验 FC r=0.97 系在训练所用 HCP 800 人组水平上计算,属拟合优度;泛化证据另见 ABCD 跨数据集 r=0.87(§2.4)`

## 方法候选词表（识别用;论文用了词表外方法则照抄原文术语）

### 模型家族

- **机理类**: 神经质量模型(Epileptor/Jansen-Rit/Wendling)、平均场(DCM 平衡点解、Deco 简化、Hansen)、网络 BNM、TVB 平台、Wilson-Cowan、Bang-bang 控制
- **数据驱动类**: MLP/RBF 代理、RNN/LSTM/GRU、CNN、Transformer、超网络(hypernetwork,静息 FC 生成任务态权重)、 reservoir computing(Echo State)
- **统计类**: VAR/SVAR、MAR(RyDynamicFC)、Bayesian 结构时序、高斯过程
- **灰盒**: 机理方程+ANN 修正项、物理信息神经网络(PINN)、DCM-AM(替代 DCM 反演的 amortized 网络)

### 验证统计量

- FC/SC/EC 矩阵相关、功率谱与特征频率、激发-抑制比、metastability、相变临界参数、发作起始区命中、递归生成不发散步长、指纹识别(个体可区分性)、test-retest ICC

### 外推测试 ground truth

- 合成数据已知参数 / CCEP 皮层电刺激 / DBS 电极记录 / 药物或麻醉状态切换 / TMS-EEG Evoked Potential / 随访结局(GOS、疗效评分) / 行为评分 / 跨数据集复现 / retest 信度
